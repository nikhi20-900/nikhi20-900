## Current focus

- **KhetSe** — shaping a farm-to-market decision-support prototype around estimated net proceeds and delivery disruptions. Its prices and scenarios are modeled, not live market data.
- **SchemeSaathi** — building a civic-tech experience with a deterministic eligibility engine and React interface. Retrieval and document intelligence are still in progress.
- **Phishing URL detection** — exploring explainable machine learning for URL risk classification.

## Selected projects

### [KhetSe](https://github.com/nikhi20-900/khetse)
A farmer-first prototype for comparing modeled selling options after estimated transport and handling costs, with a separate workflow for exploring disruption recovery.

### [SchemeSaathi](https://github.com/nikhi20-900/SchemeSaathi)
A government-scheme navigator prototype. Eligibility checks use explicit rules; the README tracks the AI/RAG and OCR work as in progress.

### [Phishing URL Detection](https://github.com/nikhi20-900/phishing-url-detection)
A Python app that classifies URLs with a Random Forest model and uses SHAP to show which URL features influenced a prediction.
